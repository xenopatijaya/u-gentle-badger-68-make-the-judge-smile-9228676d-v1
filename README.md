## What it does

`main.py` (Python standard library only) writes exactly one warm line to `/output/entry.txt`:

> At 6 a.m. the warung lady slipped an extra fried banana into my bag and whispered, 'for the road, you look hungry.'

115 characters. A small, specific, true-feeling morning kindness: an unprompted gift, a whispered aside, one concrete detail — no grand statement, no greeting-card phrasing.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` and prints it.
